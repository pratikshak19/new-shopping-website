# Trendify

Shop the trend. Live the style.

Live site: https://new-shopping-website.vercel.app

## Highlights

- **New Collections** — New Season Drop, Wedding & Festive Edit, Campus Edit, Workwear Refresh, Ethnic Heritage, Weekend Casuals, Premium Occasionwear and Conscious Picks.
- **Rent Clothes** — rent selected gowns, lehengas, sherwanis, tuxedos, suits and festive clothing for 2–10 days with a refundable deposit, cleaning and scheduled pickup.
- **Buy or Rent on product pages** — eligible products show both purchase and rental options with date and duration selection.
- Shopping features including wishlist, compare, coupons, style assistant, quiz, festival looks, kits, orders and simulated checkout.
- Firebase Web SDK foundation with Firestore and Storage security rules.

## Main routes

- `/` — home
- `/shop` — all products with collection and Buy/Rent filters
- `/collections` — new curated collections
- `/rentals` — clothes available on rent
- `/style` — AI-style assistant
- `/documents` — project documents and downloads

## Run locally

```bash
npm install
npm run dev
```

Payments and rental bookings are simulated for the college project; no real money is charged.
