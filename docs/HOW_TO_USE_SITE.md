# Trendora — kaise use karein

## Customers (sab log)

1. Site kholo.
2. Sign in (`/login`) ya Create account (`/register`).
3. Register: naam, email, 10-digit mobile, password → Send OTP.
4. Screen pe OTP dikhega, ya `123456` type karo.
5. Shop → product → Add to bag → Checkout (paisa nahi katega).

Unhe Admin, Add item, Delete **nahi** dikhta.

## Aap (admin)

1. Address bar mein `/staff` likho, ya footer mein chhota **Staff**.
2. `admin@trendora.in` / `admin123`.
3. **Add a new item**: naam → price → photo → Publish.
4. Shop pe naya card dikhega.
5. Catalogue se Edit / Hide.

Yeh desk sirf aapke login se khulta hai.
