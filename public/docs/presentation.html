College / vlg project · 2025–26

Trendora

A shopping website in the spirit of Meesho, Myntra and Flipkart.

Discover → decide → pay → track. Built as a complete React store, not a single HTML page.

01 · Why

Why a shopping site?

  • Everyone in the class already shops online.
  • E-commerce teaches data, money, identity and UX together.
  • A five-minute live demo beats a dozen screenshots.
02 · Problem

The problem we solved

Build a site where a guest or member can complete a full purchase journey without a real warehouse or payment gateway — and still feel like a national store.

03 · Inspiration

Three apps, one store

Myntra

Fashion PDP, wishlist hearts, size & colour, rose accent.

Flipkart

Deals timer, coupons, MRP break-up, COD.

Meesho

Approachable prices, category-first tiles, mobile bag.

04 · Objectives

What had to ship

  • Multi-category catalogue (32 SKUs, 8 departments)
  • Search, filter, sort
  • Bag, wishlist, coupons
  • Auth, checkout, order timeline
  • Report + slides + build notes
05 · Stack

Technology

  • React 18 + Vite — fast lab start
  • React Router — a URL per screen
  • Context API — one store for the shop
  • localStorage — survives refresh
  • Hand-written CSS tokens — every rule is explainable
06 · Architecture

Three layers

UI pages → StoreContext (use cases) → products.js + localStorage.

Presentation, application state, persistence. Draw this if they hand you a marker.

07 · Modules

Screens

Home · Shop · Product · Cart · Checkout · Orders · Wishlist · Login · Register · Profile · About · Contact · FAQ

Plus Navbar, Footer, ProductCard, toasts, image fallbacks.

08 · Data

Catalogue is data

Each product is an object: id, brand, category, price, mrp, rating, stock, colors, sizes, tags.

Adding a SKU is one object — not a new HTML page. That is the point of a component architecture.

09 · Live demo

Five-minute script

  • Land on the hero, click Women
  • Open a dress, pick size, add to bag + heart
  • Apply FESTIVE20
  • Checkout with a 6-digit PIN
  • Choose UPI (simulated) → show order id
10 · Money

The only formula that matters

grand = subtotal − coupon + shipping

Shipping is ₹79, or free above ₹999, or free with FREESHIP.

11 · Offers

Coupon engine

  • TREND10 — 10% above ₹799
  • FESTIVE20 — 20% above ₹1,999
  • WELCOME100 — ₹100 above ₹499
  • FREESHIP — delivery = 0
12 · Persistence

Refresh does not empty the bag

Everything sits under trendora-store-v1. Clearing site data is the “factory reset” for a second demo.

13 · Testing

Twelve cases we ran

Search, filters, two sizes of one SKU, coupon min-cart, good PIN, bad PIN, place order, refresh, 404, mobile drawer.

14 · Be honest

What this is not

  • No real money moves
  • Passwords are not hashed on a server
  • Nothing ships to a pincode

It is a simulation with production UX — and we say so in the FAQ.

15 · Next

Future scope

16 · Close

Trendora is ready for the lab

Defendable architecture. Demoable journey. Printed report. Step-by-step slides.
